repr () /str () 就是典型例子：同一个函数，可以传给完全不同类型的对象  啥意思啊 举个例子
一句话
repr() 只是一个单独的顶层函数，你传给它整数、日期、有理数、账户实例都行，它不用改代码，自动适配不同类型。
repr(对象) → 自动调用 对象.__repr__()
str(对象) → 自动调用 对象.__str__()
例子 1：传给内置不同类型
python
运行
from datetime import date

print(repr(123))                # 传入int
print(repr(3.14))               # 传入float
print(repr(date(2025,10,1)))    # 传入date对象
print(repr([1,2,3]))           # 传入list
print(repr({"a":1}))           # 传入dict

输出：
plaintext
123
3.14
datetime.date(2025, 10, 1)
[1, 2, 3]
{'a': 1}

✅ 同一个函数 repr()，接收了 int/float/date/list/dict 多种完全不同类型的值，全部正常工作。
原理：
repr(x) 内部不写一堆 if type(x) is int: ... elif type(x) is date: ...
它只做一件事：调用 x.__repr__()
每个类型自己写好自己的__repr__，repr不用管你是什么类型。
例子 2：我们自己新建一个类（自定义类型）
python
运行
class Account:
    def __init__(self, balance):
        self.balance = balance
    def __repr__(self):
        return f"Account({self.balance})"

# 实例
acc = Account(1000)
print(repr(acc))   # Account(1000)

👉 重点来了：Python 在设计 repr() 的时候，根本不知道以后我们会写出 Account 这个类。
但只要我们给 Account 实现__repr__，直接丢给 repr() 就能跑。
对比：如果用【类型分发】（if elif）写，是什么样子
python
运行
# 类型分发版本，不推荐
def my_repr(x):
    if type(x) == int:
        return str(x)
    elif type(x) == date:
        return f"datetime.date({x.year},{x.month},{x.day})"
    elif type(x) == Account:
        return f"Account({x.balance})"
    else:
        return "<unknown>"

❌ 缺点：每次新增一个类，必须修改 my_repr 函数，加 elif 分支。
而内置repr()（共享接口方案）：新增类，完全不用修改 repr 本身，只需要在新类写__repr__。
str () 完全同理
python
运行
print(str(123))
print(str(date(2025,10,1)))
print(str([1,2,3]))

总结原文那句话
repr 是泛型函数，可以接收多种不同类型的值
含义：
函数本身逻辑不变，但是可以接收多种不同类型的参数；每种类型自己实现同名方法，函数自动转发调用。
这个机制就是共享接口，也就是 OOP 多态。
