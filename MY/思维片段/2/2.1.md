原文：
The values we have used so far are instances of a small number of native data types that are built into the Python language.
我们目前使用的值是 Python 语言内置的少数几种原生数据类型的实例。
原生数据类型（native /built-in 内置类型）：Python 出厂自带、语言底层就支持好的数据类型，不用自己定义。
前面第一章写代码用到的：整数 int、浮点数 float、布尔值 bool、函数（一等函数）都属于内置原生类型。
5 是 int 的一个实例（具体的值），3.14 是 float 的实例。
There are expressions that evaluate to values of native types, called literals.
存在一些表达式，它们的求值结果是原生类型的值，这些表达式被称为字面量。
字面量（literal）：直接写在代码里，一眼就能看出值是多少，不需要计算、不需要调用函数，写出来就代表它本身。
例子：
python
运行
123        # int字面量
3.14       # float字面量
True       # bool字面量
"hello"    # 字符串字面量（后面会学）

对比：
1 + 2 不是字面量！它是运算表达式，需要求值才得到 3。
而 3 本身就是字面量。
一句话：字面量 = 直接写出常量本身
There are built-in functions and operators to manipulate values of native types.
有内置函数和运算符可用于操作原生类型的值。
运算符：+ - * / > == 这类符号，用来操作原生数据
内置函数：Python 自带，不用 import，例如 abs()、max()、int()
示例：
python
运行
