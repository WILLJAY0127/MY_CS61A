第一句：当我们把函数值归为数据的一种时，就意识到数据本身也可以具备行为
底层含义（CS61A 核心：一等函数 first-class function）
最开始朴素认知：
数据：静态的东西（数字、字符串），被动，等着被函数处理
函数：动作、操作，主动，用来处理数据
但 Python 里函数是一等公民：函数可以赋值给变量、放进列表、当作参数传递、作为返回值 → 函数本身就是一类数据。
既然函数（数据）能被调用执行逻辑，就推导出结论：数据不只是静态的值，它可以自带可执行的行为。
简单例子
python
运行
def greet():
    print("hi")

# greet 这个函数，是数据（可以赋值）
f = greet
# 同时它有行为：可以调用执行
f()
👉 f 是变量存着函数（它属于数据），同时能跑逻辑（具备行为）。
这一步还不是面向对象，只是函数式的基础思想，是铺垫！后面才引出对象。
第二句：对象和其他对象交互的逻辑，与描述自身取值的信息封装在一起
关键词：封装（encapsulation）
拆开两部分打包在同一个对象里：
自身信息（状态 / 数据）：比如 date(2014,5,13) 的年、月、日
交互逻辑（方法 / 行为）：两个日期相减求间隔、strftime 格式化、判断星期等（也就是这个对象怎么和别的对象打交道的规则）
旧写法（数据和逻辑分开）：
python
运行
# 数据单独放
year, month, day = 2014,5,13
# 函数单独写，外部接收数据去处理
def get_weekday(y, m, d):
    ...
对象写法（打包在一起）：
python
运行
tues = date(2014,5,13)
# 数据：tues.year, tues.month
# 交互逻辑内置在对象内部：tues.strftime()、date1 - date2
✅ 重点：不用外部单独写一堆全局函数去操作数据，数据自己就带着和外界交互的规则。
两句的递进关系（非常重要，教材的逻辑线）
一等函数：数据可以携带行为（函数式层面的思想）
对象封装：把【数据 + 配套交互行为】打包成一个整体（面向对象的核心）
一句话浓缩
一等函数告诉我们：数据能附带动作；
对象更进一步：把事物本身的数据、以及它和别的东西打交道的全套规则打包成一体。
