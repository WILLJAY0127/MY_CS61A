# 键盘快捷键训练手册：练出「高手丝滑感」

> **一句话目标**：手不离主键区、大脑不检索命令、每个动作 0.5 秒内完成。
>
> 丝滑感的来源不是记住了多少键，而是把**一小撮高频键**练成肌肉记忆。

---

## 〇、核心理念

1. **少而精**：一次只练 5 个键，练到不用想再换下一批。
2. **戒鼠标**：想用鼠标的瞬间，先想「这个动作的键位是什么」。
3. **建立映射**：终端和编辑器共用一套心智模型（`⌃A/⌃E`、按词移动两边通用）。
4. **用真实作业练**：做 hw03 的循环本身就是训练场。

---

## 一、终端层（zsh / readline）

高手的终端从不按住方向键逐字移动，全是 `Ctrl` 组合键：

| 按键 | 作用 | 典型场景 |
|---|---|---|
| `⌃A` / `⌃E` | 跳到行首 / 行尾 | 命令开头少了个 `python3 -m`，`⌃A` 一跳就改 |
| `⌥B` / `⌥F` | 按词后退 / 前进 | 长命令中间改一个词 |
| `⌃W` | 删除前一个词 | 打错路径的最后一截 |
| `⌃U` / `⌃K` | 删到行首 / 删到行尾 | 整条命令重打 |
| `⌃R` | **反向搜索历史** | 最重要！重复跑命令不用重打 |
| `⌃L` | 清屏 | 比 `clear` 快 |
| `⌃D` | EOF / 退出 | 退出 python REPL |
| `⌃P` / `⌃N` | 上一条 / 下一条历史 | 等价于 ↑↓ 但手不离主键区 |
| `⌥.` (Esc+.) | 插入上一条命令的最后一个参数 | `mkdir foo` 后想 `cd foo`：敲 `cd ⌥.` |
| `!!` | 重复上一条命令 | 权限不足 → `sudo !!` |

**实战绑定工作流**（改代码 → 跑 doctest → 再改）：

```
⌃R → 输 doct → 回车        # 搜出 python3 -m doctest hw03.py -v
看到 fail → 切回编辑器改   # 不用清屏不用重打
⌃R → 回车                  # 再跑
```

全程手不离键盘——这就是 terminal 感的来源。

## 二、编辑器层（Trae / VS Code, macOS）

### 2.1 光标移动（先练这五个）

| 按键 | 作用 |
|---|---|
| `⌥←` / `⌥→` | 按词跳（snake_case 一跳一个词） |
| `⌘←` / `⌘→` | 行首 / 行尾 |
| `⌃A` / `⌃E` | 同上（emacs 风格，和终端一致） |
| `⌘↑` / `⌘↓` | 文件顶 / 底 |
| `⇧⌘\` | 跳到匹配括号：对着 `def` 的冒号按，直达函数结尾 |

### 2.2 多光标（高手的标志性操作）

| 按键 | 作用 |
|---|---|
| `⌘D` | 选中当前词，再按一次选下一个相同词 |
| `⌘⇧L` | 选中所有相同词，全部变成光标 |
| `⌥⌘↑` / `⌥⌘↓` | 上下加光标，竖着批量编辑 |
| `⌥` + 鼠标拖 | 列选择（矩形选区） |

改名示范：想把 `count` 全改成 `total` → 光标放上去 → `⌘⇧L` → 直接打字，全部同步。

### 2.3 行级编辑（写代码手感核心）

| 按键 | 作用 |
|---|---|
| `⌥↑` / `⌥↓` | 整行上下移动 |
| `⇧⌥↑` / `⇧⌥↓` | 整行复制一份 |
| `⇧⌘K` | 删整行 |
| `⌘/` | 切换注释（调试时临时注释一行 137 这样的可疑行极常用） |
| `⌘]` / `⌘[` | 缩进 / 反缩进 |
| `⌘X` / `⌘C`（无选中） | 剪切 / 复制整行 |
| `⌘⌫` / `⌥⌫` | 删到行首 / 删前一个词 |

### 2.4 导航与修复（不开文件树）

| 按键 | 作用 |
|---|---|
| `⌘P` | 按文件名打开文件 |
| `⇧⌘O` | 文件内跳符号（输函数名直达 `def`） |
| `F12` / `⌃-` | 跳到定义 / 跳回来 |
| `F2` | 重命名符号（跨文件安全重命名） |
| `⌘.` | 快速修复（黄波浪线时按） |
| `⇧⌥F` | 格式化整个文件 |
| `⌃\`` | 切换终端面板 |
| `⇧⌘P` | 命令面板：忘了键位就搜动作名 |
| `⌘K ⌘S` | 快捷键总表 |

## 三、Vim 层（终极形态，可选但强烈推荐）

规律和前两层一致：**手不离主键区，用模式切换代替鼠标**。

| 按键 | 作用 | 对应关系 |
|---|---|---|
| `h j k l` | 左 下 上 右 | 代替方向键 |
| `w` / `b` | 按词前进 / 后退 | ≈ 终端 `⌥F` / `⌥B` |
| `0` / `$` | 行首 / 行尾 | ≈ `⌃A` / `⌃E` |
| `dd` / `yy` / `p` | 删行 / 复制行 / 粘贴 | ≈ `⇧⌘K` / `⇧⌥↓` |
| `ciw` | 改写整词（change in word） | ≈ `⌘D` + 打字 |
| `ggdG` | 全选删除 | ≈ `⌘A` + `⌫` |

- 入门材料：终端跑 `vimtutor`，30 分钟入门，每天 15 分钟一周成型。
- 不必全面转 Vim：Trae 装 **VSCodeVim** 插件，保留 GUI 便利只用核心键位（`j/k`、`ciw`、`dd`）。

---

## 四、训练方法论

1. **每批只练 5 个键**：第一周只练 `⌃R`、`⌃A`、`⌃E`、`⌥←→`、`⌘D`。
2. **强制戒鼠标一周**：想拿鼠标时先想键位，想不起来 `⇧⌘P` 搜——这是唯一内化方式。
3. **终端 ↔ 编辑器共用一套模型**：不是两套技能，是一套心智模型。
4. **作业循环即训练场**：改代码（多光标）→ 跑测试（`⌃\`` + `⌃R`）→ 注释排查（`⌘/`），每天十遍。
5. **丝滑底线四件套**：`⌃R`（终端历史）+ `⌘D/⌘⇧L`（多光标）+ `⌥↑↓`（行移动）+ `⌃\``（不离开编辑器跑测试）。练熟即超 90% 的人。

## 五、hw03 实战训练清单（当前作业沙盘）

结合正在做的 hw03（Recursion / Tree Recursion），每天 10 分钟按此序列刻意练：

| # | 动作 | 键位序列 | 练什么 |
|---|---|---|---|
| 1 | 打开 hw03.py | `⌘P` → 输 `hw03` | 文件导航 |
| 2 | 跳到 `count` 函数 | `⇧⌘O` → 输 `count` | 符号跳转 |
| 3 | 跑一遍 doctest | `⌃\`` → `⌃R` → 回车 | 终端历史复用 |
| 4 | 批量重命名一个变量 | 选中 → `⌘⇧L` → 打字 | 多光标 |
| 5 | 临时注释可疑行 | 行上按 `⌘/` | 行级编辑 |
| 6 | 把某行上移调整结构 | `⌥↑` | 行移动 |
| 7 | 复制一行做对照实验 | `⇧⌥↓` | 行复制 |
| 8 | 从函数结尾跳回 def | `⇧⌘\` | 括号匹配跳转 |
| 9 | 改完再跑测试 | `⌃\`` → `⌃R` | 循环闭合 |
| 10 | 回到刚才编辑位置 | `⌃-` | 往返导航 |

每天把 1–10 完整走一遍，一周后手会自己动。

## 六、每日计划

| 阶段 | 内容 | 达标标准 |
|---|---|---|
| 第 1 周 | 终端 5 键 + `⌘D` + `⌃\`` | 不想、不看来回切换 |
| 2 周 | 行级编辑 + `⌘P` / `⇧⌘O` | 全程不碰鼠标 |

## 附：忘了键位怎么办

- `⇧⌘P` → 搜动作名（如 "move line"），键位直接显示。
- `⌘K ⌘S` → 打开全部快捷键面板。
- 终端 `bindkey` → 列出所有 readline 绑定。
