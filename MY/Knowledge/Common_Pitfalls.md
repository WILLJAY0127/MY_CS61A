# 全局易错点清单

> 持续更新。发现一个通用的坑(不止某一讲/某一题特有),就在这里加一条。跟某个项目或某一讲强相关的坑,记到对应笔记的"关键纠错与突破"段就好,不用都塞到这里。

## 格式

### <坑的简短标题>
- **场景**:什么情况下会踩这个坑
- **错误理解**:当时以为是什么
- **正确理解**:实际是什么
- **来源**:哪一讲 / 哪道题

---

### 组合 ≠ 抽象
- **场景**: 看到一段代码把多个变量/表达式拼在一起,就以为"这就是抽象"
- **错误理解**: 把东西拼起来(组合)= 抽象;给一段代码起个名字 = 抽象
- **正确理解**: 组合只是拼装,抽象是拼装后**加边界、隐藏细节**。判据:修改内部实现,外部调用代码要不要改?要改=没抽象,不改=有抽象。随便起个名字但不屏蔽细节,只是命名,不是抽象
- **来源**: Lec01&02(Jace 思维片段 `1.md`、`想法3.md`)

### 叶子节点 ≠ 只是数字
- **场景**: 判断表达式树里哪些是叶子(原始表达式,不再向下拆)
- **错误理解**: 叶子只能是数字字面量
- **正确理解**: 叶子有两类——**数字字面量和名字(标识符)**。`add`、`pow`、`square` 这种函数名也是叶子,它绑定的值是函数对象。判断口诀:看见 `xxx(...)` 就是内部节点(调用表达式),其余都是叶子
- **来源**: Lec01&02(Jace 思维片段 `1.2.5.md`)

### 赋值绑的是值,不是关系
- **场景**: `radius=10; area=pi*radius*radius` 之后改 `radius`,`area` 不变
- **错误理解**: area 绑的是"π×r²"这个公式关系,改 radius 应该跟着变
- **正确理解**: 赋值规则是"先把等号右边所有表达式算完得到具体值,再把名字绑到这个值上"。area 绑的是 314 这个值,不是关系。Java 里 `int area = r*r` 一模一样
- **来源**: Lec01&02(字幕 2.2、教材 1.2.4)

### def 执行时函数体不立即执行
- **场景**: 看到 `def square(x): return mul(x, x)` 就以为乘法已经算了
- **错误理解**: def 语句执行时,函数体里的表达式会立即求值
- **正确理解**: def 做三件事:①创建新函数对象 ②把函数体**藏起来**(squirrel)作为函数对象的一部分 ③把函数名绑到函数对象上。函数体定义时不执行,只在调用时才执行(此时新建本地帧→形参绑实参→执行函数体)
- **来源**: Lec01&02(字幕 2.4、教材 1.3.2)
