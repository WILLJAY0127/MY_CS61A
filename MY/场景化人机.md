# 场景化人际交互世界模型搭建手册 v0.1
> **文档状态声明**：本手册为初始骨架版本，**尚不完善**。当前核心覆盖一对一、中低复杂度的人际沟通、交易、谈判、博弈场景，尚未完整覆盖多方博弈、动态系统演化、极端非理性场景等复杂情况。所有框架、变量清单与结论均需在真实交互、交易、合作、冲突事件中持续验证、补充、修正，通过实践迭代逐步完善。
>
> **体系定位**：本手册属于「顶层决策者-中间世界模型-下层执行层」完整决策框架中，**中间层世界模型的人际交互子模块**，向上对接顶层价值判断，向下输出决策依据，同时受四层校验护栏约束。

---

## 第一部分 核心定义与体系定位
### 1.1 单人视角下的「人际世界」
从单一决策者的视角出发，**你的人际世界 = 所有能与你产生因果交互、影响你的效用收益、接收你行动反馈的独立主体、规则、客体、信号，沿时间线展开的总和**。
它不包含与你无任何交互链路的客观事物，只覆盖进入你决策链路的部分。

### 1.2 场景化模型的核心价值
本手册聚焦人际交互类场景的模型搭建，目标是解决三个核心问题：
1. 进入一个场景时，**该提取哪些输入变量**，避免凭直觉遗漏关键信息；
2. 不同场景下，**变量的权重优先级是什么**，合理分配认知算力；
3. 模型与现实出现偏差时，**如何定位问题、迭代修正**，形成闭环。

### 1.3 搭建的底层原则
- **模型是简化工具，不是真相本身**：所有模型都在裁剪信息，必须明确适用边界；
- **可验证优先于自洽**：逻辑自洽的模型如果预测失效，必须修正，不能强行解释现实；
- **迭代优先于完美**：先有骨架，再通过真实事件补全细节，不追求一步到位。

## 第二部分 通用变量提取框架
所有人际交互场景通用，共6大类。进入任意场景后按此扫描，可系统性降低变量遗漏概率。

### 2.1 主体变量（每个参与方单独提取）
对每一个独立主体（自己、对方、第三方），分别提取以下维度：
- **长期底色**：稳定价值观、核心偏好、底线原则、与你的信任/关系存量、历史行为模式
- **当下状态**：精力水平、情绪状态、压力负荷、时间焦虑、认知带宽、是否受外部催促
- **本次诉求**：表层立场（公开表达的要求）、底层利益（真正想要的结果）、不可接受的代价
- **能力与权限**：掌握的信息、决策权限、认知盲区、可调动的资源
- **激励约束**：对谁负责、考核标准是什么、收益由谁决定、违约/失败的代价

### 2.2 场景与上下文变量
- **场景属性**：信息交换 / 立场宣告 / 情绪宣泄 / 关系结盟 / 交易议价 / 合作谈判 / 利益博弈
- **时间维度**：紧急程度、截止期限、选择可逆性、是单次交互还是长期重复博弈
- **渠道与环境**：当面/电话/文字/公开会议，是否有旁观者、第三方决策者
- **历史上下文**：过往恩怨、未兑现的承诺、之前的共识与分歧、未解决的遗留问题

### 2.3 信息变量
- **信息分布**：各方分别掌握哪些私有信息，哪些是公开共识
- **信息可验证性**：哪些是可核实的硬事实，哪些是口头承诺、主观判断、廉价表态
- **验证成本**：核实一条信息需要付出的时间、金钱、信任成本
- **信号真伪**：对方的行为是真实能力/意愿的信号，还是刻意伪装的表演

### 2.4 规则与结构变量
- **正式规则**：法律、合同、制度、流程、双方明文约定
- **非正式规则**：行业惯例、潜规则、人情规范、圈子共识、道德默认约束
- **权力结构**：谁拥有决定权、否决权、资源分配权、规则解释权
- **退出成本**：任何一方终止交互、违约、破裂关系，需要付出的直接与间接代价

### 2.5 动作空间与后果变量
- **己方可选动作**：全部可行选项，不止第一反应的两三个
- **对方可能应对**：对方针对每个动作，可能做出的全部反馈
- **直接后果**：每个动作带来的即时收益、即时成本
- **二阶/连锁后果**：单次选择带来的长期影响，如信任损耗、口碑变化、未来合作空间变化

### 2.6 噪声与随机变量
- 不受任何一方控制的外部偶然因素
- 无法稳定预测、不值得强行建模的随机波动
- 作用：区分“模型错误”和“运气波动”，避免无意义的自我追责

### 2.7 关键区分：硬观测变量 vs 软推断变量
这是避免模型自欺的核心规则，所有变量必须强制分类：
| 类型 | 定义 | 示例 | 处理原则 |
|------|------|------|----------|
| 硬观测变量 | 可直接确认、客观存在的事实 | 对方的职位、公开的报价、已发生的历史事件 | 直接作为模型输入 |
| 软推断变量 | 你基于经验推测、无法直接验证的判断 | 对方的真实诉求、对方的底线、对方的情绪 | 必须标注为「假设」，预留验证与修正空间 |

> 核心警示：人天生会把自己的推断当成事实，这是模型失效的第一大原因。所有软推断变量，都必须在事中事后做验证。

## 第三部分 分场景核心模型与变量清单
不同场景下变量权重天差地别，以下为各场景的高权重核心变量，优先提取、优先校验。

### 3.1 场景分类与核心逻辑
| 场景类型 | 核心逻辑 | 目标 | 高权重变量类型 |
|----------|----------|------|----------------|
| 日常沟通/观点分歧 | 信息交换、共识达成 | 传递信息、化解分歧、维护关系 | 信任存量、情绪状态、目标共识 |
| 交易/买卖/报价 | 价值交换、价格博弈 | 达成对己方有利的交易 | 双方估值、替代选项、信息差、违约成本 |
| 合作谈判 | 利益拆分、长期协同 | 达成可持续的合作协议 | BATNA、利益可拆分性、信任存量、退出成本 |
| 利益博弈/竞争冲突 | 资源争夺、胜负对抗 | 保障己方利益、限制对方收益 | 收益结构、背叛惩罚、权力结构、重复博弈属性 |

### 3.2 场景A：日常沟通与观点分歧
**核心模型**：沟通交换模型 + 情绪交互模型
**必抓核心变量**：
1. 双方对沟通目标的共识（是求真，还是争输赢）
2. 双方的情绪状态与认知带宽
3. 双方的信任存量与历史分歧
4. 是否有第三方在场（是否需要维护立场）
5. 时间压力与沟通渠道的信息损耗

**适用边界**：双方默认遵守基本沟通规则、有基本共识意愿；若对方已进入立场对抗模式，场景自动切换为博弈类。

### 3.3 场景B：交易、买卖与报价
**核心模型**：供需模型 + 信息不对称模型 + 议价模型
**必抓核心变量**：
1. 双方对标的物的估值（使用价值 / 交易价值）
2. 双方各自的替代选项（有没有其他买家/卖家）
3. 信息差（对方知道多少你的底线、你知道多少对方的成本）
4. 交付风险与违约成本
5. 资金时间成本与长期合作预期
6. 双方的时间紧迫程度

### 3.4 场景C：合作谈判与长期磋商
**核心模型**：谈判利益模型 + 重复博弈模型 + 信任模型
**必抓核心变量**：
1. 各方BATNA（最佳替代方案，谈判的核心锚点）
2. 利益的可拆分空间（哪些可以让步、哪些不能）
3. 双方的信任账户存量与承诺可验证性
4. 各方的决策权限与背后约束
5. 合作破裂的退出成本
6. 长期合作的预期收益与风险

### 3.5 场景D：利益博弈与竞争冲突
**核心模型**：非合作博弈模型 + 威慑模型
**必抓核心变量**：
1. 收益结构：零和、正和还是负和
2. 行动顺序：同步行动还是先后行动
3. 博弈次数：单次博弈还是重复博弈
4. 信息透明度：双方底牌是否可见
5. 背叛的惩罚机制与可信度
6. 权力结构与外部约束

### 3.6 场景切换识别信号
现实交互中场景会动态变化，出现以下信号时，必须立刻切换对应模型，避免模型越界：
- 对方停止讨论事实、开始重复立场 → 从「沟通」切换为「立场博弈」
- 对方开始报出具体价格、提出交换条件 → 从「沟通」切换为「交易」
- 对方开始引入第三方、公开表态站队 → 从「一对一谈判」升级为「多方博弈」
- 对方出现明显情绪失控、人身攻击 → 从「理性博弈」切换为「情绪冲突应对」

## 第四部分 标准运转流程（事前-事中-事后闭环）
### 4.1 事前：场景匹配与变量提取
1. **场景判定**：先判断当前属于哪类场景，匹配对应模型
2. **变量扫描**：按6大类框架提取变量，优先提取高权重核心变量
3. **假设标注**：所有软推断变量全部标记为「假设」，不默认是事实
4. **算力校验**：评估自身状态，确认认知带宽足够支撑推演；状态不佳时降低决策复杂度
5. **边界预判**：预估可能出现的场景切换信号，提前准备应对预案

### 4.2 事中：跟踪校验与动态调整
1. **预期对照**：观察对方反应是否符合模型预期
2. **失效预警**：出现严重偏离预期的情况，优先假设「我的模型漏了变量/假设错误」，而非「对方反常」
3. **低成本验证**：通过提问、试探、旁敲侧击验证关键软假设
4. **动态修正**：根据新信息调整变量权重，必要时切换场景模型
5. **二阶后果提醒**：做选择前，快速校验长期连锁影响，避免短期最优、长期受损

### 4.3 事后：复盘迭代与模型更新
1. 结果对照：对比事前预测和实际结果
2. 偏差归因：区分四类偏差来源
   - 变量遗漏：漏掉了关键维度
   - 权重错误：高估/低估了某个变量的影响
   - 模型错配：用错了场景模型
   - 随机噪声：不可控的偶然因素
3. 模型更新：补充遗漏变量、修正权重、明确模型边界
4. 沉淀入库：将新的规律、变量、边界补充进对应场景的模型库

## 第五部分 已知缺口与后续迭代方向
本版本为初始骨架，以下维度尚未完整落地，是后续实践迭代的重点方向：
1. **变量权重量化机制**：当前仅做定性优先级区分，未建立不同场景下的量化权重标准，算力分配精度不足
2. **多回合动态演化**：当前以静态快照为主，未完整覆盖多回合交互中变量的联动、反馈回路与演化规律
3. **多方博弈模块**：当前核心覆盖一对一交互，未完整覆盖三方及以上的联盟、站队、委托代理等变量
4. **非理性行为适配**：对极端情绪驱动、潜意识驱动、认知闭合状态下的非理性行为，解释与应对模型不足
5. **自身状态校准工具**：缺少客观校验自身情绪、精力状态的标准化方法，自我感知易失真
6. **模型失效预警体系**：事中识别模型出错的信号清单尚未系统化，止损切换的判断标准不够清晰
7. **长期连锁后果评估**：二阶及以上的间接、长期后果，尚未形成结构化的评估框架
8. **结构约束的量化**：社会规则、行业周期、制度等结构性约束，对交互的影响程度缺少可落地的评估方法

## 第七部分 阶段性验收标准
所有标准均可自检、可观测，用于判断当前阶段的掌握程度，避免无体感的“假进步”。

### 7.1 入门阶段（0-1个月）验收标准
**目标**：完成从「凭感觉判断」到「结构化提取变量」的跨越
- 面对单次沟通、简单交易场景，能主动按6大类框架扫描变量，不会只盯着表面话术
- 能明确区分「硬事实」和「我的推测」，不会把假设当成默认前提
- 事后复盘时，能稳定找出至少1个事前遗漏的关键变量
- 能准确识别4类基础场景，不会用沟通模型去应对博弈场景
- 完成至少10次真实交互的结构化复盘，手册中有对应的沉淀记录

### 7.2 进阶阶段（1-3个月）验收标准
**目标**：建立动态校验意识，模型预测准确率明显提升
- 不同场景下能快速抓住3-5个核心高权重变量，不会在次要变量上过度消耗算力
- 交互过程中能识别出「模型预期偏离」的信号，主动调整策略，而非一条路走到黑
- 能稳定识别场景切换，及时更换对应模型，不会出现明显的模型越界
- 复盘时能准确区分偏差来源：变量遗漏 / 权重错误 / 模型错配 / 随机噪声
- 面对简单谈判、常规交易，事前预判的结果与实际结果的吻合度达到60%以上
- 完成至少30次真实交互复盘，形成自己的常见变量清单与易错点清单

### 7.3 高阶阶段（3-6个月）验收标准
**目标**：形成稳定的模型迭代闭环，能处理中等复杂度的多回合交互
- 面对多回合谈判、长期合作等动态场景，能主动考虑二阶连锁后果，不追求单次最优
- 能自主搭建新场景的变量框架，不依赖现成清单
- 能同时用两套竞争模型解读同一个场景，互相校验，减少单一视角盲区
- 能清晰说出自己常用模型的适用边界与失效条件，不会强行用模型解释所有现象
- 重大决策的事后复盘，不会出现“当初完全没想到这个变量”的低级遗漏
- 形成个人专属的模型库，覆盖日常高频场景，且持续保持更新

### 7.4 最终形态目标（长期）
- 拥有一套适配自身生活、工作、交易场景的，经过大量真实事件验证的世界模型库
- 面对陌生场景，能快速搭建临时变量框架，做出比直觉更可靠的判断
- 模型与顶层价值体系高度对齐，工具服务于目标，不会陷入为了优化而优化的内卷
- 清晰知道自己模型的边界，承认有大量不可控、不可建模的部分，不追求全知全能

### 8.3 分层自检问句清单
#### 事前快速自检
1. 我判断的场景类型，真的对吗？
2. 有没有哪个关键变量，是我默认假设、但没验证的？
3. 我现在的状态，适合做这个判断吗？

#### 事中失效预警
1. 对方的反应，完全在我预期之外吗？
2. 我是不是在强行用现有模型解释反常现象？
3. 我有没有忽略这个选择的长期代价？

#### 事后复盘校准
1. 这次偏差，是模型问题，是执行问题，还是纯运气？
2. 我有没有把自己的推测当成了事实？
3. 这个场景的模型边界，需要修正吗？
