## Getting Started \[5 minutes]

### Q1: Warm Up

**原题（English）**

What is the value of `result` after executing `result = (lambda x: 2 * (lambda x: 3)(4) * x)(5)`? Talk about it with your whole group and make sure you all agree before anybody checks the answer.

> **中文**：`result = (lambda x: 2 * (lambda x: 3)(4) * x)(5)` 的值是多少？跟组里讨论再对答案。

**答案**

```
30
```

**说明**

从里往外拆，每一步都是一个独立的 call expression：

1. 内层 call：`(lambda x: 3)(4)` → body 是常量 `3`，跟参数 `x` 无关 → 直接得 `3`
2. 外层 body 化简：`2 * 3 * x = 6x`
3. 外层 call：`(lambda x: 6x)(5)` → `6 * 5 = 30`

关键点：lambda 的参数 `x` 是形参名，内层和外层各有一个 `x`，**互不干扰**。内层那个 `x` 被 `4` 绑定了但完全没用，所以内层直接返回常量 3。

**关联知识点**

- lambda 是 expression：求值时只产函数对象，body 不执行；body 只在调用时才执行
- 短路 / 运算顺序：call expression 里 operator 和 operands 都是先求值再调用
- 对接 Lec04 · Lambda Expressions

**易错点**

- 以为 `(lambda x: 3)(4)` 里的 `4` 参与了计算 → 没有，body 是常量 3，参数根本没用
- 运算优先级搞错：以为 `2 * (lambda x: 3)(4) * x` 里 `2 *` 先算 → 不是，先算 call expression

## Call Expressions \[15 minutes]

**原题（English）**

Draw an environment diagram for the code below. You can use paper or a tablet or the whiteboard. Talk to your group about how you are going to draw it, then go through each step together. Then, step through the diagram generated by Python Tutor to check your work.

> **中文**：画下面代码的环境图。跟组里讨论每一步怎么走，再上 Python Tutor 对答案。

```python
def team(work):
    return t(work) - 1
def dream(work, s):
    if work(s-2):
        t = not s
    return not t
work, t = 3, abs
team = dream(team, work + 1) and t
```

**最终状态**（核心产出）

| 帧      | 名字    | 绑定值                           |
| ------ | ----- | ----------------------------- |
| Global | team  | `abs`（Python 内置函数）            |
| Global | dream | function dream（parent=Global） |
| Global | work  | 3                             |
| Global | t     | `abs`（**从头到尾没被改**）            |

> dream 帧里有一个局部 `t = False`，但它只活在 dream 函数的调用帧里，dream return 后帧销毁，那个 t 跟着消失。Global 的 t 从头到尾都是 abs。

**关键追踪步骤**

- `def team(work):` → Global 创建 function team（parent=Global）
- `def dream(work, s):` → Global 创建 function dream（parent=Global）
- `work, t = 3, abs` → Global 绑定 work=3，t=**内置函数 abs**（Python 自带的 `abs()`）
- `team = dream(team, work + 1) and t` → 右边先全算完再写左边
  - 先算 `dream(team, work + 1)`：
    - work + 1 = 3 + 1 = 4
    - 调用 dream（参数 work=function team, s=4），创建 dream 帧（parent=Global）
    - dream 帧里 `if work(s-2)` → work 是 function team → 调用 `team(s-2) = team(2)`
      - 创建 team 帧（parent=Global），work=2
      - `return t(work) - 1` → t 在 team 帧找不到 → 沿 parent=Global 找 → **t=abs** → abs(2) - 1 = 2 - 1 = **1**
      - team 帧销毁，返回 1
    - 回到 dream 帧，`work(s-2) = 1` → if 条件为真（1 是真值）
    - `t = not s` → **dream 帧里创建局部名 t = not 4 = False**（非零整数是 True，not True 是 False）
    - `return not t` → t 是 False → not False = **True**
    - dream 帧销毁，返回 True
  - 现在算 `True and t` → t 是 Global 里的 abs（真值）→ **and 返回 abs**（Python `and` 短路：左边 True 就返回右边的值）
  - team 绑定到 abs

**考点清单**（这道题一次覆盖 6 条环境图规则）

- **函数内赋值只建局部名**：dream 里的 `t = not s` 是 dream 帧的局部名，Global 的 t 完全不受影响——**这就是为什么最后 t 还是 abs**
- **同名参数遮蔽外层名字**：dream 的形参也叫 `work`，遮蔽了 Global 的 work=3，但 dream 里没用到 work 的数值，所以没踩坑
- **名字查找沿 parent 向上**：team 函数里 `return t(work) - 1`，t 在 team 帧找不到 → parent=Global → 找到 abs
- **赋值右边先全算完，左边统一写回**：`team = dream(team, work + 1) and t` 里的 team 直到右边算完才写左边
- **Python and/or 返回值不是布尔值**：`True and abs` 返回 abs，不是 True
- **Python 内置函数 abs**：t 绑定的是 Python 自带的 `abs()`，不是这个文件里定义的任何东西

**验证**

```python
>>> abs(-5)
5
>>> abs(0)
0
>>> team(-5)  # team 现在是 abs
5
```

**易错点**

- 以为 dream 里 `t = not s` 改了 Global 的 t → **完全没有**，局部名只活在 dream 调用帧里，dream 返回后帧销毁。Global 的 t 从头到尾都是 abs
- 以为 dream 返回了 function team → dream 返回的是 True（布尔值），但 `True and abs` 最终让 team 绑定到 abs
- 把 `abs` 当成这个文件里定义的函数 → 它是 Python 内置的，在任何模块里都可以直接用
- 漏了 dream 调用里嵌套的 team 调用 → dream 是高阶函数调用：`work(s-2)` 里的 work 本身就是一个函数

### Q2: Make Keeper

**原题（English）**

Implement `make_keeper`, which takes a positive integer `n` and returns a function `f` that takes as its argument another one-argument function `cond`. When `f` is called on `cond`, it prints out the integers from 1 to `n` (including `n`) for which `cond` returns a true value when called on each of those integers. Each integer is printed on a separate line.

> **中文**：`make_keeper(n)` 返回一个函数 `f`，`f(cond)` 会打印 1 到 n 中所有让 `cond(i)` 为真的整数，每行一个。

**Starter**

```python
def make_keeper(n):
    """Returns a function that takes one parameter cond and prints
    out all integers 1..i..n where calling cond(i) returns True.

    >>> def is_even(x): # Even numbers have remainder 0 when divided by 2.
    ...     return x % 2 == 0
    >>> make_keeper(5)(is_even)
    2
    4
    >>> make_keeper(5)(lambda x: True)
    1
    2
    3
    4
    5
    >>> make_keeper(5)(lambda x: False)  # Nothing is printed
    """
    "*** YOUR CODE HERE ***"
```

**提示（Hint）**

To return a function `f`, include `def f(cond):` as the first line of the implementation and `return f` as the last. The `f` function should introduce `i = 1` in order to loop through all integers, calling `cond(i)` to determine whether `cond` returns true for each integer.

> **中文**：外层 `make_keeper` 先 `def f(cond)` 再 `return f`；内层 `f` 里 `i = 1` 开始循环，每轮调 `cond(i)` 判断。

**答案**

```python
def make_keeper(n):
    def keeper(cond):
        for i in range(1, n + 1):
            if cond(i):
                print(i)
    return keeper
```

**验证**

```python
>>> make_keeper(5)(is_even)     # doctest
2
4
>>> make_keeper(5)(lambda x: True)
1
2
3
4
5
>>> make_keeper(5)(lambda x: False)  # Nothing printed
```

**思路**

两层函数结构：外层 `make_keeper(n)` 接收上界 n，内层 `keeper(cond)` 接收判断函数。内层循环 `for i in range(1, n+1)` 从 1 跑到 n，每轮用 `cond(i)` 判断当前 i 是否满足条件，满足就 print。

**关联知识点**

- 外层返回函数、内层做循环——高阶函数"返回函数"的典型结构
- `cond` 是**判断函数**（只返回 True/False），跟 Disc 01 Q1 Race 里的 `while tortoise - hare` 同根：把"判断条件"抽象成一个函数，交给调用方传进来
- 对接 Lec04 · Higher-Order Functions，教材 Section 1.6

**易错点**

- 循环里写成 `cond(n)` 而不是 `cond(i)` → 每次都检查同一个固定值 n，循环变量白跑。这是写高阶函数最常见的变量名混用 bug
- 忘记 `return keeper` → `make_keeper(n)` 返回 None，调用链 `make_keeper(5)(is_even)` 直接 TypeError
- 用 `while i <= n` 而不是 `for range` → 记得手动 `i += 1`，否则死循环。两种循环都对，但 `for range` 更简洁安全

### Q3: Digit Finder

**原题（English）**

Implement `find_digit`, which takes in a positive integer `k` and returns a function that takes in a positive integer `x` and returns the `k`th digit from the right of `x`. If `x` has fewer than `k` digits, it returns 0.

For example, in the number 4567, 7 is the 1st digit from the right, 6 is the 2nd digit from the right, and the 5th digit from the right is 0 (since there are only 4 digits).

**Important:** You may not use strings or indexing for this problem. Try to solve this problem using only one line.

> **中文**：`find_digit(k)` 返回函数，该函数接收 `x` 返回 `x` 的右数第 `k` 位；位数不够返回 0。**不能用字符串或索引，尝试一行解决**。

**Starter**

```python
def find_digit(k):
    """Returns a function that returns the kth digit of x.

    >>> find_digit(2)(3456)
    5
    >>> find_digit(2)(5678)
    7
    >>> find_digit(1)(10)
    0
    >>> find_digit(4)(789)
    0
    """
    assert k > 0
    "*** YOUR CODE HERE ***"
```

**提示（Hint）**

- Lambda expressions.
- Use floor dividing by a power of 10 gets rid of the rightmost digits.

> **中文**：用 lambda；除以 10 的幂能砍掉右边的数字。

**答案**

```python
def find_digit(k):
    assert k > 0
    return lambda x: (x // 10 ** (k - 1)) % 10
```

**验证**

```python
>>> find_digit(2)(3456)
5
>>> find_digit(2)(5678)
7
>>> find_digit(1)(10)
0
>>> find_digit(4)(789)
0
```

**思路**

两步走：先砍、再取。

1. `x // 10 ** (k - 1)`：把目标位**右边**的数字全部砍掉，让目标位变成个位
2. `% 10`：取出个位，就是答案

以 `find_digit(2)(3456)` 为例：k=2 → `10 ** 1 = 10` → `3456 // 10 = 345` → `345 % 10 = 5`。

指数是 `k - 1` 而不是 `k`，因为右数第 1 位（个位）本来就在个位上，不需要砍任何东西，对应 `10 ** 0 = 1`。

**关联知识点**

- 与 Lab 1 的 `digit(n, k)` 是同一个数学思路，只是这里把 n 变成了外层参数、用 lambda 返回内层函数
- `//` 向下取整除法用来"砍尾巴"，`%` 取余用来"取个位"，这对组合是处理十进制数位的通用套路
- 位数不够时天然返回 0：`789 // 1000 = 0`，`0 % 10 = 0`，不需要额外判断

**易错点**

- 指数写成 `10 ** k` → 整体错一位，`find_digit(1)(10)` 会得到 1 而不是 0
- 用 `str(x)[-k]` → 题目明确禁止字符串和索引
- 额外写 `if` 判断位数够不够 → 多余，整除已经天然处理了

### Q4: Match Maker

**原题（English）**

Implement `match_k`, which takes in an integer `k` and returns a function that takes in a variable `x` and returns `True` if all the digits in `x` that are `k` apart are the same.

For example, `match_k(2)` returns a one argument function that takes in `x` and checks if digits that are 2 away in `x` are the same.

`match_k(2)(1010)` has the value of `x = 1010` and digits 1, 0, 1, 0 going from left to right. `1 == 1` and `0 == 0`, so the `match_k(2)(1010)` results in `True`.

`match_k(2)(2010)` has the value of `x = 2010` and digits 2, 0, 1, 0 going from left to right. `2 != 1` and `0 == 0`, so the `match_k(2)(2010)` results in `False`.

**Important:** You may not use strings or indexing for this problem.

> **中文**：`match_k(k)` 返回函数，该函数接收 `x`，若 `x` 中所有相隔 `k` 位的数字都相同则返回 `True`。**不能用字符串或索引**。

**Starter**

```python
def match_k(k):
    """Returns a function that checks if digits k apart match.

    >>> match_k(2)(1010)
    True
    >>> match_k(2)(2010)
    False
    >>> match_k(1)(1010)
    False
    >>> match_k(1)(1)
    True
    >>> match_k(1)(2111111111111111)
    False
    >>> match_k(3)(123123)
    True
    >>> match_k(2)(123123)
    False
    """
    def check(x):
        while x // (10 ** k) > 0:
            if ____________________________:
                return ____________________________
            x //= 10
        ____________________________
    ____________________________
```

**提示（Hint）**

In each iteration, compare the last digit with the one that is `k` positions before it.

> **中文**：每轮循环比较末位和它往前数第 `k` 位。

**答案**

```python
def match_k(k):
    def check(x):
        while x // (10 ** k) > 0:
            if x % 10 != (x // (10 ** k)) % 10:
                return False
            x //= 10
        return True
    return check
```

**验证**

```python
>>> match_k(2)(1010)
True
>>> match_k(2)(2010)
False
>>> match_k(1)(1010)
False
>>> match_k(1)(1)
True
>>> match_k(1)(2111111111111111)
False
>>> match_k(3)(123123)
True
>>> match_k(2)(123123)
False
```

7 个 doctest 全过。

**思路**

核心是**错位比较**——把 x 和「x 右移 k 位后的版本」逐位对齐，每次都只比末位。

每轮循环做三件事：

1. `x % 10` 取当前末位
2. `(x // 10 ** k) % 10` 取往前数第 k 位
3. 两者不等立刻 `return False`，相等就 `x //= 10` 整体右移一位继续

以 `match_k(3)(123123)` 为例（答案 True），每轮比末位和往前数第 3 位：

| 轮次 | x | 末位 `x % 10` | 第 k 位 `(x // 1000) % 10` | 判断 |
|---|---|---|---|---|
| 1 | 123123 | 3 | `123123 // 1000 = 123`，`123 % 10 = 3` | 相等，继续 |
| 2 | 12312 | 2 | `12312 // 1000 = 12`，`12 % 10 = 2` | 相等，继续 |
| 3 | 1231 | 1 | `1231 // 1000 = 1`，`1 % 10 = 1` | 相等，继续 |
| 4 | 123 | — | `123 // 1000 = 0` | 退出循环 → `True` |

对照 `match_k(2)(123123)`（答案 False）：第一轮末位是 3，往前数第 2 位是 `123123 // 100 = 1231` 的末位 1，`3 != 1`，立刻返回 False。

**关联知识点**

- 与 Q3 `find_digit` 同一套数位技巧：`//` 砍尾巴、`%` 取个位；Q3 是取第 k 位返回，这里是取第 k 位用来比较
- `x //= 10` 相当于"整体右移一位"，是把数字当数位序列遍历的标准写法
- 循环条件不是 `x > 0` 而是 `x // 10 ** k > 0`——这个条件是本题的精髓，决定了什么时候"没有可比的了"
- `while` 里提前 `return False`、循环外 `return True` 是"找反例"型判断的通用骨架

**易错点**

- `x %= 10` 当成表达式用 → `%=` 是赋值语句，不能出现在 `!=` 左边。必须写 `x % 10`（你原稿这里踩了）
- 循环条件写成 `x > 0` → 会多跑几轮，此时 `(x // 10 ** k) % 10` 恒为 0，遇到末位非 0 就误判 False。例如 `match_k(1)(1)` 会得到 False，正确答案是 True
- 忘记 `x //= 10` → 死循环
- 循环结束后写成 `return False` → 反了，走到循环结束说明没找到反例，应该 `return True`
- 用 `str(x)` 逐字符切 → 题目明确禁止字符串和索引

## 本次踩的坑

- **`x %= 10` vs `x % 10`**：`%=` 是赋值语句，只能在语句位置；想拿余数参加比较必须用 `%`（Q4）
- **外层参数与内层循环变量混用**：`make_keeper` 里写成 `cond(n)` 而不是 `cond(i)`，导致每轮检查同一个固定值（Q2）
- **指数差一位**：取右数第 k 位时指数是 `k - 1`，不是 `k`（Q3）
- **函数内赋值只建局部名**：`dream` 里 `t = not s` 只改 dream 帧，Global 的 `t` 仍是 `abs`（Call Expressions）
